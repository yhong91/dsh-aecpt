# AeCpt 科研工作台（学生端）

AeCpt 科研工作台将 DeepSeek Harness (DSH) 连接到课题组自托管的 AeCpt 服务端。可从左侧插件栏打开 **AeCpt 科研工作台**，或在任意对话窗口右上角点击 **进展总结** 快速提取本次对话的科研进展。

## 概览

**概览** 首页集中展示三块高频信息：

- **科研进展**：通栏展示当前教学周的状态、已收集的过程片段数、一键进入查看/编写周报，以及最近收到导师反馈的周次（点击直达对应周报与反馈）。
- **近期计划**：以周一至周日 7 天日历条展示本周未完成任务数量（默认选中今天），逾期未完成项单独聚合提示。
- **文献订阅**：展示本机 RSS/Atom 与 arXiv 订阅的未读条目。

## 教学周科研进展（碎片汇总 + 一键提炼周报）

- **邀请链接自动映射与浏览器 OAuth PKCE 授权**：插件不硬编码服务器地址。在工作台点击「连接工作台」并粘贴导师发来的邀请链接（或服务器地址），即可自动映射课题组服务器并在浏览器中用学号完成注册/授权。令牌仅保存在 DSH Host 凭据库中，不经对话或大模型传递。
- **对话进展提取**：点击对话右上角 **进展总结**，系统自动归属到当前教学周；可按需勾选本会话前序或工作区过往片段作为承接脉络，一键将本次新增对话提取为精炼片段存入「本周汇总」池（带会话进度点，重复提取仅处理新增轮次）。
- **一键提炼与融合完整周报**：在「科研进展」中可随时在 **本周汇总 (N)** 与 **完整周报** 间切换，支持手动补记/两步删除片段，并一键调用模型将零碎记录提炼为结构化完整周报；若已有手改正文，再次提炼会进入增量融合模式并支持一键撤销。
- **离线编辑与提交**：支持 Markdown 与 KaTeX 数学公式（行内 `$x^2$`，块级独立 `$$` 行）、离线保存、重连自动同步与三路冲突合并；提交后锁定周报并接收导师反馈。
- **自定义提示词**：可在本机 `~/.aecpt/dsh/prompts.json` 中自定义 `fragment_system` 与 `compile_system` 系统提示词。

## 个人计划与选择性共享

在 **计划** 中通过 **清单** 与 **月历** 管理个人任务（可设截止日期与关联项目）。计划默认仅本人可见；如需同步给导师，可为已保存条目选择在职导师并在预览确认后发布当前快照。后续修改默认保持私密，需手动更新分享，也可随时撤回。

## 文献订阅

在 **文献订阅** 中订阅期刊 RSS/Atom、arXiv 学科预设或自定义检索与研究博客。订阅源与缓存仅保存在本机 `~/.aecpt/dsh/`（按账号隔离），不上传服务端。

## 课题组公用论文库

- **公用库**：按关键词、标签检索已入库论文，展开摘要、查看推荐理由、下载 PDF 或复制/批量导出 `.bib` 文件。
- **提交论文**：输入 DOI 或 arXiv 编号/链接在本机解析元数据（或手工填写），支持 arXiv 自动下载 PDF 或上传本地 PDF（≤50 MB），经导师审核通过后对全课题组可见。
- **我的投稿**：追踪待审核、已入库与未通过投稿，查看退回意见、修改待审核条目标签或撤回投稿。

## Agent 工具

内置 `aecpt_authorize`、`aecpt_authorize_complete`、`aecpt_logout`、`aecpt_me`、`aecpt_report`、`aecpt_plan`、`aecpt_feeds` 与 `aecpt_library` 八个工具，供对话与自定义 Skill 直接调用工作台能力。面向二次开发的服务端接口说明见 `docs/SERVER_API.md`。
